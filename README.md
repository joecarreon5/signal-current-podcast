# Signal Current Podcast

Public web player and RSS feed for **Signal Current**, the weekly AI and emerging-technology
intelligence briefing for agency, communications, advertising, marketing, and business leaders.

This repository contains published media only. The private collection, ranking, editorial, and
delivery engine lives separately.

- Website: <https://joecarreon5.github.io/signal-current-podcast/>
- RSS: <https://joecarreon5.github.io/signal-current-podcast/feed.xml>

Episodes and pages are generated by the private Signal Current production workflow. This site does
not contain tracking scripts, advertising, or forms that collect listener information.
